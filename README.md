Entry untuk bounty make.fun ["Make the best game"](https://make.fun/bounty/best-game-01): **STARFORGE**, game survival arena gravitasi neon. Sumur gravitasi menangkap asteroid ke orbit — orbit itu perisai sekaligus amunisi: klik/Spasi melempar batu terluar, E melepaskan NOVA yang melontarkan seluruh orbit. Bunuh beruntun dalam 2 detik menumpuk kombo NOVA CHAIN. Sepuluh gelombang, empat jenis pemburu, bos Devourer dua fase, dan draft upgrade 3 kartu dari 12 pilihan dengan sinergi. Menang di bos terakhir: STAR IGNITED.

## Run

```sh
node main.ts   # menyalin game/ + screenshots/ ke output dan menulis dossier.json
```

Buka `game/index.html` di browser desktop untuk bermain. Kontrol: WASD/panah bergerak, mouse membidik, klik/Spasi melempar batu, E/Shift NOVA, R mengulang.

Daftar make.fun lewat referral kami: https://make.fun/r/1bdkx9mj
